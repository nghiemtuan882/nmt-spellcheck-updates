# Phần mềm hỗ trợ sửa chính tả

Add-in kiểm tra chính tả tiếng Việt cho Microsoft Word (Windows và Mac).

## Tải bộ cài

Vào mục **Releases** (bên phải) → bản mới nhất (Latest), tải:

- **Windows:** NMT-SpellCheck-x.y.z-Windows.exe
- **Mac:** NMT-SpellCheck-x.y.z-macOS.zip

Các tệp còn lại (latest.json, .pack, nmt-bridge-...) dùng để phần mềm tự cập nhật, không cần tải.
